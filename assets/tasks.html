Two tasks

Two questions about one series

Every detector answers one of them; state detectors answer both, since a change of state is a change point.

Change point detection

Where does the behaviour change?

The detector returns the sorted indices where a new segment starts. Scored by F1, Covering, Gaussian F1 and Hausdorff distance.

State detection

Which recurring state is each point in?

The detector returns one label per time point, and a state can come back. Scored by ARI, NMI, their weighted versions and the State Matching Score.
